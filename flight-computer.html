Flight Computer — Wiring Schematic & Compact Layout

Hover · obstacle avoidance · level flight · autopilot cruise · planet scan
Reading this: each lane is one subsystem — sensor(s) on the left, logic in the middle, actuator on the right. Dots mark port type the way the game colors them: red = power, yellow = data in, blue = data out. Dashed lines cross subsystems (e.g. the obstacle trip reaching into the attitude loop, or the scanner handing a lock to the autopilot). The vertical red spine on the left is the power run — every block with a red dot taps it via Frame‑Quarter‑With‑Ports, not a separate cable.
Timing: the game runs at 60 ticks/s and every block takes one tick (16.7 ms) to pass a signal on, so a lane's response time is its block count in ticks. Parts shown are ones the game's own part list confirms; circuits for lanes 04 and 05 are planet_hop_v2.json and raster_sweep.json.
